## Overview

Networking endpoints expose the service-network model: server-wide network
membership, one instance's observed connectivity, and the desired ingress
routes derived from stack `ingress:` + `ports:`. All require a bearer token.

## GET /v1/networks

`GET /v1/networks` returns the server-wide network membership summary (default
+ named networks) with member instances and ports, plus `exposedPorts` — every
claimed `expose` port with its owning `stack`/`service` (`{port, stack,
service}`). Claims are exclusive server-wide, so this is the authoritative
owner map; `mc2 network` renders it.

```
GET /v1/networks
Authorization: Bearer mc2at_...
```

```bash
curl -s -H "Authorization: Bearer $MC2_API_KEY" "$MC2_API/v1/networks"
```

```json
{
  "networks": [
    {
      "name": "api",
      "kind": "default",
      "stacks": ["api"],
      "instances": [
        {"instanceId": "6bee1f2c-...", "stack": "api", "service": "w", "ordinal": 0,
         "runtimeId": "api--w--0", "phase": "Running", "healthy": false,
         "nodeId": "422229db-...", "exposePorts": [], "ports": []}
      ]
    }
  ],
  "exposedPorts": []
}
```

`kind` is `default` (a stack's own network) or `named`.

## GET /v1/instances/{id}/network

`GET /v1/instances/{id}/network` returns the observed network status for one
instance (reported by the reconcile loop).

```
GET /v1/instances/{id}/network
Authorization: Bearer mc2at_...
```

Response fields: `instanceId`, `phase`, `message`, `updatedAt`, and `observed`
(`edges` it can reach, `exposes` it serves, `message`) — the reconcile loop's
last report. Returns `404` when there is no network status for the instance.

```bash
curl -s -H "Authorization: Bearer $MC2_API_KEY" "$MC2_API/v1/instances/$ID/network"
```

## GET /v1/ingress

`GET /v1/ingress` lists the desired ingress routes derived from stack YAML
and the chosen backend replica. Whether a route is ready (and so written to
Traefik's file) is visible in `catalog.json` under `--ingress-config-dir`.

```
GET /v1/ingress
Authorization: Bearer mc2at_...
```

The response is `{ "routes": [...], "note": "..." }`. Each route has `id`,
`stack`, `host`, `path`, `pathType`, `service`, `guestPort`, `hostPort`,
`bind`, `tlsEnabled`, `certResolver`, `backendInstanceId`, `backendOrdinal`,
and `nodeId`.

```bash
curl -s -H "Authorization: Bearer $MC2_API_KEY" "$MC2_API/v1/ingress"
```

<Callout type="note" title="Ingress file readiness">
  `GET /v1/ingress` is desired state only — the Traefik file catalog lives
  under `--ingress-config-dir` and is written by the server's reconcile loop.
</Callout>
