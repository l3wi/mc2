---
title: Agent swarm
description: Scale one service to a fleet of microVMs, reach them all through one name, and have MC2 replace any that stop answering.
---

## What you'll build

One service definition becomes four microVMs, each with its own kernel. They
share one exposed port, so any caller on the network reaches "the swarm" by
name and MC2 spreads connections across the replicas. A health check lets
MC2 replace a replica whose process dies.

```text
                     agent:18200   (one name, one port)
                           │
                  MC2 splice, round-robin
        ┌─────────────┬────┴────────┬─────────────┐
        ▼             ▼             ▼             ▼
   agent/0       agent/1       agent/2       agent/3
   microVM       microVM       microVM       microVM
```

You need a running server and a CLI context — see the
[Quickstart](/documentation/quickstart).

## The stack

Save as `agent-swarm.yaml`:

```yaml
name: agent-swarm
networks:
  mesh:
    mode: mediated
services:
  agent:
    image: python:3.12-alpine
    scale: 4
    mem_limit: 256m
    networks: [mesh]
    expose: [18200]
    restart: always
    command: ["/bin/sh", "-c", "cat /proc/sys/kernel/random/boot_id > /tmp/index.html && cd /tmp && exec python -m http.server 18200"]
    healthcheck:
      test: ["CMD", "wget", "-q", "-O", "/dev/null", "http://127.0.0.1:18200/"]
      interval: 2s
      retries: 2
      start_period: 10s
```

- `scale: 4` — four replicas, each its own microVM.
- `expose: [18200]` — one port for the whole service, not one per replica.
  Exposed ports are unique on the server, so pick one nobody else uses.
- `networks: [mesh]` — also join a server-wide named network, so agents in
  **other** stacks can reach this swarm as `agent.mesh.svc.mc2`.
- `restart: always` + `healthcheck` — replace a replica that stops
  answering, not just one whose VM stops.
- The `command` stands in for your agent: it serves the VM's boot ID, so you
  can see which replica answered.

<Note title="Scale is bounded by the host">
  `scale × cpus` and `scale × mem_limit` must fit the host (and any
  `--limit-*` budget), or the apply is refused. `mc2 status` shows capacity
  and what's reserved.
</Note>

## Run it

<Steps>

<Step title="Apply">

```bash
mc2 up -f agent-swarm.yaml
mc2 ps --stack agent-swarm      # repeat until all four are Running
```

</Step>

<Step title="Call the swarm from inside it">

```bash
for i in 1 2 3 4; do mc2 exec agent-swarm/agent/0 wget -qO- http://agent:18200/; done
# 9a4c1da8-1a67-4c8a-ad05-e2005a3635b6
# a301ce37-ab32-42ff-b02c-2fe51cd1e6a2
# f7cf4096-70a8-4a0f-8cb7-f53688d84e95
# 3aeb6c4b-34b6-4a0a-8b49-4f8490dd3da2
```

Four different boot IDs: connections round-robin over the ready replicas.
Inside the stack the name is `agent` or `agent.agent-swarm.svc.mc2`; from
another stack on `mesh`, it's `agent.mesh.svc.mc2`.

</Step>

<Step title="Look at the network">

```bash
mc2 network mesh
```

```text
network 'mesh' (named) — 1 stack, 1 service, 4 instances (4 active)
  agent-swarm/agent  0  Running  healthy
      expose: 18200 (agent-swarm/agent)
  ...
port claims (exclusive server-wide):
  18200  agent-swarm/agent
```

</Step>

<Step title="Get into one replica">

```bash
mc2 exec agent-swarm/agent/2 uname -a
mc2 logs agent-swarm/agent/2 --follow
```

</Step>

<Step title="Kill one agent and watch it come back">

```bash
mc2 exec agent-swarm/agent/3 cat /tmp/index.html          # note the boot ID
mc2 exec agent-swarm/agent/3 /bin/sh -c '(sleep 1; kill "$(pidof python)") >/dev/null 2>&1 &'
mc2 ps --stack agent-swarm -o json                         # repeat for ~10 s
mc2 exec agent-swarm/agent/3 cat /tmp/index.html          # a new boot ID
```

The health check fails twice, MC2 recreates replica 3 as a fresh microVM, and
the other three never notice.

</Step>

<Step title="Clean up">

```bash
mc2 down agent-swarm
```

</Step>

</Steps>

## Variations

- **Fully isolated agents.** Drop `networks` and `expose`: replicas then
  share only the stack's own network and serve nothing to each other. For
  egress, `network.profiles: [public]` (the default) allows the internet,
  `[private]` allows only LAN addresses, and `[none]` cuts networking
  entirely.
- **Agents that talk to a coordinator.** Put the coordinator in its own
  service with an `expose` port on `mesh`; the agents reach it by name.
- **Per-replica inspection.** `mc2 network agent-swarm/agent/2` shows what one
  replica can reach.
